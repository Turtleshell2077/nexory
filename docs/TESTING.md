## 3. Ручной E2E чек-лист

Проходить на **двух устройствах** (разные аккаунты) и минимум на двух версиях Android —
одна ниже 13, одна 13+ (из-за разрешения на уведомления).

### 3.1. Первый запуск и согласие (блокер RuStore)
- [ ] Чистая установка → онбординг → **экран согласия**
- [ ] Кнопка «Продолжить» неактивна, пока не отмечен чекбокс
- [ ] Тап «Политика конфиденциальности» → открывается в браузере, текст читается
- [ ] Тап «Пользовательское соглашение» → открывается
- [ ] После согласия → экран входа; на нём внизу видны ссылки на документы
- [ ] На экране регистрации ссылки тоже видны
- [ ] Перезапуск приложения → согласие больше не спрашивается

### 3.2. Регистрация / вход / восстановление
- [ ] Регистрация с новым ником и почтой
- [ ] Регистрация с **уже занятым ником в другом регистре** (`IVAN` при `ivan`) → понятная ошибка «Такой никнейм уже занят»
- [ ] Регистрация с занятой почтой → «Эта почта уже зарегистрирована»
- [ ] Пароль короче 8 символов → ошибка про длину
- [ ] Вход с неверным паролем → «Неверная почта или пароль» (не «HTTP 401»)
- [ ] Код подтверждения почты приходит письмом
- [ ] Восстановление пароля по коду из письма работает
- [ ] **Сессия:** войти, закрыть приложение, открыть через час → вход не требуется
- [ ] Открыть 4–5 экранов одновременно после долгого простоя → не выкидывает на вход

### 3.3. Друзья (переработанная вкладка)
- [ ] Вкладок ровно две: «Друзья» и «Запросы»
- [ ] Свайп между вкладками работает
- [ ] Кнопка «Добавить друга» разворачивается в строку поиска **в той же строке**
- [ ] Курсор автоматически встаёт в поле поиска
- [ ] Ввод ника → **над строкой поиска** появляется превью: аватар, имя, @ник
- [ ] Тап по превью **не открывает** профиль (проверить: ничего не происходит)
- [ ] Кнопка «Добавить в друзья» отправляет заявку → статус меняется на «Заявка отправлена»
- [ ] Поиск по **имени** (не нику) ничего не находит — так и задумано
- [ ] Поиск своего ника → «Это ваш профиль», добавить нельзя
- [ ] Поиск ника уже друга → «Уже у вас в друзьях»
- [ ] Несуществующий ник → «Никого не найдено»
- [ ] Крестик сворачивает поиск и очищает запрос
- [ ] Строка поиска и карточки друзей выровнены по одному левому краю
- [ ] На втором устройстве: заявка видна во «Запросах», «Принять» работает
- [ ] После принятия — тап по другу открывает **полный профиль**
- [ ] Удаление из друзей работает

### 3.4. Мероприятия
- [ ] Создание: заполнить всё → создаётся без ошибки
- [ ] Создание с пустым названием → поле подсвечивается красным
- [ ] Метро: ввод «сок» → выпадает список (Сокол, Сокольники…), выбор подставляется
- [ ] Метро отображается на карточке и в деталях («м. Сокольники»)
- [ ] Своё мероприятие в «Все мероприятия» помечено «Организатор»
- [ ] Дата создания видна в деталях
- [ ] Фильтр: уровень, метро, увлечения, «Мои увлечения» из профиля
- [ ] Редактирование своего мероприятия
- [ ] **Удаление мероприятия → чат мероприятия сохраняется** (проверить на втором аккаунте-участнике)
- [ ] Запись на чужое мероприятие, отписка
- [ ] Запись на заполненное → «Мест больше нет»

### 3.5. Чаты и WebSocket
- [ ] Отправка сообщения — доходит на второе устройство без перезагрузки
- [ ] Сообщения сохраняются после перезапуска приложения
- [ ] **Переподключение:** включить авиарежим на 30 сек → выключить → сообщения снова доходят
- [ ] Чат мероприятия появляется во вкладке «Чаты»
- [ ] Заглушить / в архив / удалить чат
- [ ] Аватар собеседника без фото — цветной генеративный, одинаковый при каждом входе

### 3.6. Оффлайн-режим
- [ ] Загрузить ленту → включить авиарежим → **лента видна**, сверху красный баннер «Нет подключения»
- [ ] В баннере указано, когда данные обновлялись
- [ ] Профиль открывается офлайн
- [ ] Чат открывается офлайн, история видна
- [ ] **Поле ввода в чате заблокировано**, плейсхолдер «Нет сети — отправка недоступна»
- [ ] Выключить авиарежим → баннер исчезает, данные обновляются сами
- [ ] Выход из аккаунта → вход другим аккаунтом → офлайн **не видно** данных первого

### 3.7. Уведомления
- [ ] Android 13+: в Настройках виден баннер «Разрешите уведомления»
- [ ] Тап → диалог с объяснением → системный запрос
- [ ] После разрешения баннер исчезает
- [ ] Push о новом сообщении приходит при свёрнутом приложении
- [ ] Отключение тумблера «Push-уведомления» → пуши не приходят
- [ ] Отказ от разрешения → приложение не падает и не спамит запросами

### 3.8. PIN-код
- [ ] Включить PIN → задать → повтор → включился
- [ ] Перезапуск приложения → просит PIN
- [ ] Неверный PIN → ошибка, вход не пускает
- [ ] Верный PIN → пускает
- [ ] Отключить PIN → перезапуск → не спрашивает

### 3.9. Поддержка проекта (донат)
- [ ] Ссылка не заполнена → «Приём переводов пока не настроен» (не пустой браузер)
- [ ] Ссылка заполнена, есть сеть → открывается страница банка
- [ ] **Номер телефона/карта получателя нигде в приложении не видны**
- [ ] Возврат в приложение → «Спасибо! Если оплата прошла успешно…»
- [ ] Авиарежим → «Нет подключения к интернету», кнопка «Попробовать снова»
- [ ] Поля ввода суммы в приложении нет (сумма вводится у банка)

### 3.10. Удаление аккаунта (блокер Google Play)
- [ ] Профиль → Настройки → Аккаунт → «Удалить аккаунт»
- [ ] Диалог перечисляет, что будет удалено
- [ ] Неверный пароль → «Неверный пароль», аккаунт цел
- [ ] Верный пароль → аккаунт удалён, приложение вышло на экран входа
- [ ] Попытка войти удалённым аккаунтом → «Неверная почта или пароль»
- [ ] На втором устройстве: мероприятия удалённого пользователя исчезли из ленты
- [ ] Страница `/legal/delete-account` открывается в браузере

### 3.11. Плохая связь и совместимость
- [ ] Медленная сеть (эмулятор, профиль EDGE) → спиннеры, без зависаний ANR
- [ ] Обрыв сети посреди отправки → понятная ошибка, приложение не падает
- [ ] Маленький экран (~5", 320dp) → тексты не обрезаны, кнопки нажимаемы
- [ ] Планшет / большой экран → верстка не разъезжается
- [ ] Тёмная и светлая темы на всех основных экранах
- [ ] Поворот экрана на ключевых экранах → состояние не теряется
- [ ] Системная навигационная полоска не перекрывает контент на онбординге, входе, регистрации
- [ ] Кнопка «Назад» с ленты закрывает приложение (стек пуст) — это ожидаемо
